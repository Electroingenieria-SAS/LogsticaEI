# V24 · Evidencias obligatorias de entrega y certificado de creación

Cambios aplicados sobre V23, sin reconstruir desde cero:

1. En todos los procesos de entrega/despacho se exige evidencia fotográfica antes de cerrar el caso:
   - Foto antes de subir mercancía.
   - Foto de mercancía subida.
   - Foto de carro correctamente cerrado o persona retirando mercancía, según el tipo de entrega.

2. Cada foto se sube por Google Drive API y queda registrada con:
   - URL de Drive.
   - Fecha y hora de cargue.
   - Usuario responsable.
   - Pedido/caso/proceso/tipo de evidencia.

3. El sistema no permite cerrar una entrega si falta cualquiera de las evidencias obligatorias.

4. Se agregó botón de Certificado de creación con autoría funcional de Juan Esteban Pérez.

5. Se conserva la funcionalidad previa: PDF obligatorio, lectura automática, cortes, Drive, SIESA, VSM, Admin y migración de procesos legacy.

Nota: el GIF del certificado se referencia desde la URL de GIPHY incluida en el archivo HTML suministrado por el usuario.
